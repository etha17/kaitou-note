解答ノート — 使い方
===================

このフォルダがウェブサイトそのものです。Claude とは切り離されているので、
置き場所を変えてもそのまま動きます。

フォルダの中身
--------------
  index.html        科目一覧（友達に送るのはこのページのリンク）
  subject.html      科目ごとの解答ページ（合言葉が必要）
  editor.html       自分用の編集ページ（写真を追加する場所）
  subjects.json     科目の名前と id の一覧
  assets/           見た目と動きのプログラム
  data/             解答データと写真（編集ページが作ります）


■ 1回だけやる準備（Netlify に置く）

1. https://app.netlify.com/drop を開く。
2. 先に Netlify のアカウントを作ってログインしておく。
   ※ ログインせずにドラッグすると、更新のたびに URL が変わってしまいます。
3. この site フォルダを、ページの枠の中にドラッグする。
4. 数十秒で https://なにか.netlify.app という URL ができる。
   「Site configuration」→「Change site name」で好きな名前に変えられます。
5. できた URL を開いて、科目一覧が出るか確認する。


■ 解答を追加・修正する

1. ブラウザで https://自分のサイト/editor.html を開く（パソコンの Chrome か Edge）。
2. 科目を選ぶ。初めてなら合言葉を決める。2回目以降は合言葉を入力する。
3. 単元を作り、「＋ 解答を追加」で問題名と写真を入れる。
   写真を直すときは「この写真を差し替え」。赤い「修正」の印が付きます。
4. 画面の下に出る「サイトのフォルダに保存する」を押し、
   パソコンにある site フォルダを選ぶ（初回だけ聞かれます）。
   ※ Chrome / Edge 以外では「ZIP で書き出す」になります。
     解凍して、site フォルダに上書きしてください。
5. Netlify の自分のサイトの「Deploys」を開き、site フォルダをドラッグして更新。
6. 友達が開くと新しい解答が表示されます。


■ 友達に渡すもの

・index.html の URL（例：https://自分のサイト/）
・合言葉（リンクとは別のメッセージで送る。会って口で伝えるのが一番安全）


■ 知っておくこと

・合言葉を知らない人には、単元名も解答の写真も読めません。
  暗号化したまま置いてあり、合言葉から作った鍵でブラウザが開きます。
・科目名（subjects.json）は合言葉なしでも見えます。
・合言葉を変えたいときは、編集ページの左下「合言葉を変更」。
  変更して保存すると、前の合言葉では開けなくなります。
・写真は長辺 1600 ピクセルに縮小して保存します。枚数の上限はありません。
・editor.html は URL を知っている人なら開けますが、合言葉がないと中身は見えず、
  サイトを書き換えることもできません（書き換えには Netlify のログインが必要）。
・data/ の中のファイルを手で消さないでください。写真が表示されなくなります。


■ パソコンだけで試したいとき

ファイルをダブルクリックして開くと、データの読み込みがブラウザに止められます。
VS Code の拡張「Live Server」でこのフォルダを開くと、手元で確認できます。
